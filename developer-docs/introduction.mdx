## Make a request

Read saved leads without changing data. Set `OUTREIGN_API_KEY` in secure server-side environment storage first.

```bash
curl --fail-with-body 'https://api.outreign.io/rest-api/leads?limit=5&offset=0' \
  -H "X-API-Key: $OUTREIGN_API_KEY"
```

The response contains `data`, `count`, `limit` and `offset`. Empty data is valid for an account with no saved leads. For new prospects use [network search](/developer-docs/prospecting), not the saved-leads endpoint.

## REST API

Find fresh B2B prospects, resolve companies, look up people and check emails. Read and manage saved leads, contacts, pipeline deals and activities; enrich, research, score or draft for a saved lead.

- Base URL: `https://api.outreign.io/rest-api`
- Authentication: an OutReign API key in the `X-API-Key` header
- [Make your first request](/developer-docs/quickstart)
- [Browse the API reference](/developer-docs/api-overview)

## MCP for AI assistants

Connect a compatible assistant to your OutReign account. The assistant can discover tools for leads, sequences, inbox replies, deals, ICP profiles and agent configuration.

- Endpoint: `https://api.outreign.io/mcp`
- Authentication: sign in and approve access using OAuth
- [Connect your assistant](/developer-docs/mcp/connect)
- [Read the tool reference](/developer-docs/mcp/tools)

## Pick the right interface

REST and MCP discovery/intelligence actions use the same app handlers and account restrictions. See [capabilities by interface](/developer-docs/capabilities) for the exact supported actions, [prospecting recipe](/developer-docs/guides/prospect-verify-save) for a complete flow, and [core concepts](/developer-docs/concepts) for the data model.

## Before you begin

Use an OutReign account with access to the feature you need. API and MCP access is available on paid plans; plan restrictions and usage limits still apply. Never place API keys, OAuth tokens or webhook secrets in public browser code.

For product setup rather than developer integration, visit the [Help Center](https://outreign.io/help). Check [API status](https://outreign.io/api-status) when troubleshooting availability.
