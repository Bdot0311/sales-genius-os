All REST endpoints use `https://api.outreign.io/rest-api`. Send `X-API-Key` on every request and `Content-Type: application/json` for JSON request bodies.

## Resources

| Resource | Operations |
| --- | --- |
| Prospecting | Fresh B2B prospect search, company autocomplete, known-person lookup and standalone email verification |
| Leads | List, create, retrieve, update, delete, bulk import, enrich, research and score saved leads |
| Deals | List, create, retrieve, update and delete pipeline deals |
| Activities | List, create, retrieve, update and delete activities |
| Contacts | List, create, retrieve, update and delete contacts |
| Outreach | Generate an email draft |
| Workspace | Existing role/plan-gated targeting, campaign, inbox, mailbox and statistics actions; edits require confirmation |

Use the endpoint groups in this tab for request fields, response shapes and code examples. The reference is generated from the [OpenAPI specification](https://outreign.io/openapi.json).

## Request anatomy

```http
POST /rest-api/leads HTTP/1.1
Host: api.outreign.io
X-API-Key: YOUR_OUTREIGN_API_KEY
Content-Type: application/json

{ "contact_name": "Jordan Lee", "company_name": "Northwind Analytics" }
```

| Header | Direction | Purpose |
| --- | --- | --- |
| `X-API-Key` | Request | Required on every call. |
| `Content-Type: application/json` | Request | Required when sending a body. |
| `X-RateLimit-Remaining` | Response | Requests left in the current minute for this key and resource. |
| `X-RateLimit-Reset` | Response | When the window refills (ISO 8601). |

## Status codes

| Code | Meaning |
| --- | --- |
| `200` | Request handled; app actions can still contain an error. |
| `201` | Created (including partial bulk imports; check `failed`). |
| `400` | Invalid JSON or missing required field. |
| `401` | Missing, invalid, inactive or expired API key. |
| `403` | Plan or authorization restriction; inspect the error. |
| `404` | Record not found in your account, or unknown resource. |
| `405` | Method not supported on this path. |
| `410` | Retired endpoint (`/workflows`). |
| `429` | Rate limited; wait until `resetAt`. |
| `500` | Unexpected error. |

Full details and retry guidance: [errors and limits](/developer-docs/errors-and-limits). What the API can and cannot do compared with the app and MCP: [capabilities](/developer-docs/capabilities).

## Versioning

The API is unversioned in the URL. Ignore unfamiliar additive response fields. Consult the [changelog](/developer-docs/changelog) for documented changes; advance notice of every breaking change is not a guaranteed service contract.

## Common conventions

- Resource IDs are UUIDs returned by OutReign; use your own account's IDs.
- Updates use `PATCH`. Contact updates preserve omitted fields; the current lead, deal and activity normalizers can clear omitted optional fields or apply defaults. Read the current record first and include writable values you need to retain, then inspect the result.
- List endpoints use `limit` and `offset`; see [pagination](/developer-docs/pagination).
- Bulk lead import accepts a `leads` array with at most 100 entries per request.
- Email generation creates a draft; it is not a send-email endpoint.
- CRUD uses `data` wrappers; delegated prospecting/intelligence/workspace actions return the app's own JSON shape. Rate-limit headers may be absent on delegated routes.
- Enrichment, scoring and generation are subject to account entitlements and usage checks. Do not treat an API key as unlimited access.

## Separate interfaces

MCP tools and webhook configuration are not REST resources in this specification. Read the [MCP reference](/developer-docs/mcp/tools) and [webhook guides](/developer-docs/webhooks/overview) for their contracts.

The legacy workflows resource is retired and returns `410`. Use OutReign's AI SDR agent for agent workflows instead.
